# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting:
<https://github.com/svg153/canvas-software-factory/security/advisories/new>.

You can expect an acknowledgement within a few days. The plugin never reads or sends
credentials itself (all GitHub access goes through your own `gh` auth); see the
"Privacy & security" section of the README for the threat model.
